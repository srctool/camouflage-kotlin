# Changelog (kotlin-lib)

All notable changes for the Kotlin library are documented here.

This changelog follows Keep a Changelog and Semantic Versioning.

## [Unreleased]
- M0: project skeleton. Kotlin Multiplatform modules (Android, iOS, JVM desktop, wasmJs) for core, the Minimal skin, navigation3 and skin-testing, plus the BOM; the `com.srctool.*` convention plugins with TestKit tests; ABI validation, Detekt, Kover and the module-layer check; the sample app on all four platforms (including the iOS Xcode project); CI.
- M1 to M14: the full v0.1 set. `camouflage-core` (theme with contrast validation, the skin contract, the provider and environment, 52 components: text, buttons, inputs and forms, structure, overlays, feedback, navigation chrome, popovers and toolbars, data components, adaptive layout), `camouflage-charts` (line, area, bar, pie, donut and sparkline charts that follow the skin), `camouflage-navigation3`, and five skins: Minimal, Fluent (Solid, Acrylic and Mica), Material 3, Cupertino (Classic and Liquid Glass) and Carbon.
- M15: accessibility checks over every gallery (a name, a role or state and a 44 dp target; 200% text and right to left), tree toggles and icon-only navigation items named for screen readers.
